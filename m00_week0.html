Python 自测：三小题

第②档的分界线在这里。逐段读下面的代码，能看懂大意（不必每行都解释）即通过。 三段都选自课程真实会遇到的代码形态：

自测 1 · dataclass：M04 配置系统的地基python
from dataclasses import dataclass

@dataclass
class TrainConfig:
    lr: float = 1e-4
    epochs: int = 2

cfg = TrainConfig(lr=3e-4)
print(cfg.lr, cfg.epochs)  # 这行输出什么？
自测 2 · 列表推导与 zip：M12 "错一位"的最小原型python
tokens = [1, 2, 3, 4]
pairs = [(cur, nxt) for cur, nxt in zip(tokens, tokens[1:])]
print(pairs)  # 这行输出什么？
自测 3 · with open：课程里所有"读文件"的标准姿势python
with open("config.yaml", encoding="utf-8") as f:
    text = f.read()
# 离开 with 块，文件已自动关闭——即使中途抛了异常

三段的参考答案：1 输出 0.0003 2（dataclass 让"带默认值的类"一行一个字段， 不用写 __init__）；2 输出 [(1, 2), (2, 3), (3, 4)] （zip 把序列与它的右移版对齐——这就是语言模型"用前一个词预测后一个词"的数据形态）； 3 没有输出，但你知道 text 里是文件全文、文件已经关好。 三题全通，你就是第②档以上。

检验一下

测验 1 · 为什么 python -c "import json" 一点输出都没有？

验收第三盏灯的判定标准是"无输出即绿"。可命令明明"执行成功"了，它为什么一句话都不说？想要它开口，有什么办法？

答案：import 成功时本来就静默——Python 只在失败时说话（抛 ModuleNotFoundError）。想看到"成功"的证据，让它做一件可见的事：python -c "import json; print(json.__file__)"——输出的路径还顺便告诉你正在用的是哪个解释器，这个技巧在变式练习里马上用到。

答错回看：M00 验收 的第三盏绿灯。

测验 2 · 环境变量到底是干什么的？这门课里谁已经用上了？

提示：本页命令行三件套里它排第三；M01 有一件"数据就位"的事全靠它。

答案：环境变量是"整个终端会话里所有程序都能读到的全局配置值"，作用是把配置写在代码外面——换一台机器、换一个数据目录，代码一行不改。这门课的第一个出场者是 MINIMIND_REBORN_DATA_ROOT（M01 数据就位）：训练数据不进 git 仓库，代码靠这个变量找到你的数据根目录。

答错回看：命令行三件套 的体检示例 + 本页词汇表"环境变量"。

测验 3 · git clone 完成之后，怎么知道"这个仓库最近在改什么"？

答案：两步：git log --oneline 先看提交历史（一行一条，拿到 hash）；对哪条感兴趣，再 git show <hash> 看那次提交的具体改动。这正是本课程 bug 猎场的标准动作——先定位"案发现场"的 commit，再读修复 diff。

答错回看：git 最小集 的三行表。

变式练习

🧪 变式 · uv run python -c "print(1)" 和裸 python -c "print(1)" 有什么差别？

在任意目录（暂不需要克隆仓库）先后执行：

$ python -c "print(1)"
$ uv run python -c "print(1)"

先写下预测：两条命令的输出相同吗？它们用的是同一个 Python 解释器吗？为什么？

观察结果与解释（先动手再看）

输出相同——都是 1。但"是谁打印的"未必相同：用 python -c "import sys; print(sys.executable)" 和 uv run python -c "import sys; print(sys.executable)" 各验一次， 多半会看到两个不同的路径。

机制：裸 python 用的是 PATH 环境变量里排第一个的解释器——哪来的用哪的； uv run 则由 uv 决定"该用哪个 Python"：在包含 pyproject.toml 的项目目录里， 它会自动创建/同步锁定环境（.venv）再执行——首次可能花几分钟下载依赖， 这正是 M01 uv sync 做的事；在项目之外，它用 uv 托管的解释器。

这 30 秒的观察是 M01"锁定环境、逐位一致"的第一块拼图： 同一行代码，换一个解释器，依赖与版本就换了一个世界——课程把"用哪个 Python"从运气变成约定。

本课词汇

终端 terminal
敲命令、看输出的文本界面；这门课的"驾驶舱"，每节课都在这里度过。
环境变量 environment variable
整个终端会话里所有程序都能读到的全局配置值，把配置写在代码外面（如 MINIMIND_REBORN_DATA_ROOT）。
虚拟环境 virtual environment
为一个项目单独安装的一套依赖，与系统和其他项目隔离；reborn 的 .venv 由 uv 按锁文件创建，逐位一致。
PATH
一个环境变量：终端按它列出的目录顺序查找你敲的命令——裸 python 用谁的，由它决定。
