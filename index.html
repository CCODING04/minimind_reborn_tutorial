快速开始

五分钟拿到第一个绿灯

  1. 先完成 M00 · Week-0 准备：三档受众自测 + 最小工具箱 + 三盏版本绿灯（约 40 分钟，会 PyTorch 者约 5 分钟）；
  2. 准备 Python 3.12+ 与 uv（课程唯一指定工具链）；
  3. cd Reproduce/minimind_reborn && uv sync --extra dev 安装锁定环境；
  4. uv run python tools/verify_env.py 验证 torch / CUDA；
  5. 数据就位：设置 MINIMIND_REBORN_DATA_ROOT 指向数据目录，或用 tools/download_data.py 从 ModelScope 下载；
  6. make smoke —— tiny 模型 pretrain→SFT→DPO 全链路冒烟，11 秒内三段全绿。

全过程逐步讲解见 M01 · 课程导览与第一个绿灯。

常见问题

我需要什么基础？
先做 M00 · Week-0 准备 的三档自测：完全零基础有先修资源路线，会 Python 不懂 PyTorch 正是主线的设计对象（PyTorch 即需即讲），会 PyTorch 可直接进 M01。默认期望是会 Python 和基本 PyTorch（张量、autograd、nn.Module）；LLM 零经验可以，每个概念都会在使用处即需即讲，重推导折叠可跳。
没有 GPU 能学完吗？
能。主线全部使用 tiny 配方（64 维 2 层模型，笔记本 CPU 可跑）与 reborn 的真实存档（训练日志、指标、权重）；64M 实训全部标注 🎮 选做。
minimind_reborn 和官方 minimind 是什么关系？
reborn 是官方 minimind 的工程化重构：权重 state_dict 逐键兼容（官方权重可直接 strict 加载）、tokenizer 相同，差异在工程层——配置系统、数据管线、测试、分布式与可观测性。课程以 reborn 为主线，官方仓在对照评测（M21）中登场。
公式断网会坏吗？
公式渲染库（MathJax）与全部样式脚本已本地化到课程目录——整站完全离线可用，无任何外部资源依赖。
